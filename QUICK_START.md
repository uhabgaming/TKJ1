## ⚡ QUICK START GUIDE - GOYAL GAYIL SNACK

### 🚀 Mulai Cepat dalam 3 Langkah:

#### 1️⃣ **Buka Website**

```
Buka file: index.html
di folder: Web Toko
```

Double-click file `index.html` → Website terbuka di browser!

#### 2️⃣ **Test Fitur**

- 🔍 Coba search produk
- 🏷️ Filter berdasarkan kategori
- 🛒 Add produk ke keranjang
- 📱 Checkout ke WhatsApp

#### 3️⃣ **Customize** (Optional)

- Edit `script.js` → Ganti nomor WhatsApp
- Edit `style.css` → Ganti warna
- Edit `index.html` → Ganti text/gambar

## 🆘 Jika Ada Problem

### Website tidak buka?

- Cek apakah file ada di folder
- Coba buka dengan browser lain
- Cek format file (harus `.html`)

### WhatsApp tidak buka?

- Cek nomor format benar (62...)
- Pastikan WhatsApp terinstall
- Cek koneksi internet

### Produk tidak muncul?

- Refresh browser (Ctrl+F5)
- Buka console (F12) untuk lihat error
- Cek file `script.js` tidak ada error
