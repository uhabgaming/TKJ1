### 📝 **Instruksi Penggunaan**

#### Setup:

1. Buka file `index.html` di browser
2. Semua fitur sudah siap digunakan

#### Customization:

1. **Ganti Gambar Hero**: Edit link di `<img src="...">` di section hero
2. **Ganti Nomor WhatsApp**: Edit `WHATSAPP_NUMBER` di script.js atau link di footer
3. **Ganti Warna**: Edit CSS variables di `:root` section di style.css
4. **Tambah Produk**: Edit array `products` di script.js
